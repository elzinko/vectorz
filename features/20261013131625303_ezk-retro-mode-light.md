# 20261013131625303 — ezk-retro : un mode light

**En clair.** `ezk-retro run` déroule toujours sa cérémonie complète (round-robin 2 tours, juge,
rangement). Pour un petit périmètre — une friction ponctuelle, un run court — c'est parfois trop
lourd. On veut un **mode light** : une rétro courte (symptômes → 2-3 propositions typées → capture),
sans le round-robin multi-agents, tout en gardant les garde-fous (symptôme + mesure, capture, feu
vert PO).

**Si tu arrives frais.** `ezk-retro` est la cérémonie d'auto-amélioration de la méthode : une équipe
d'agents débat, un juge vérifie, le PO range. Le mode light en serait une version allégée.

## Contexte / Problème

Demande PO (2026-10-13, rétro du run v0.12). Aujourd'hui `ezk-retro` n'a qu'un seul mode, complet
et coûteux (plusieurs appels d'agents). Une « rétro légère » a déjà été jouée à la main plusieurs
fois (ex. run v0.5) faute d'option dédiée : le besoin est réel et récurrent. Ce n'est pas une option
d'`ezk-retro` aujourd'hui — à construire.

## Proposition *(à groomer)*

Un déclencheur light, par ex. `ezk-retro run --light <périmètre>` (nom à fixer au grooming) : saute
le round-robin multi-agents, garde la collecte des signaux, produit 2-3 propositions typées
(symptôme + mesure), écrit la capture, laisse le PO trancher. Les garde-fous durs (pas de règle sans
symptôme + mesure, capture obligatoire, feu vert PO) restent.

## Critères d'acceptation

- [ ] Un mode light existe et produit une capture valide (`ezk retro captures --check`).
- [ ] Il garde les garde-fous : symptôme + mesure, capture, feu vert PO, réversibilité.
- [ ] Il coûte sensiblement moins que la cérémonie complète (pas de fan-out multi-agents).
