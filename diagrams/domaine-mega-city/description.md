# Le domaine mega-city — comment les objets s'articulent (prose source)

Demande PO (2026-08-24) : l'onglet « le domaine » de la carte donne un glossaire, mais il
manque UN schéma qui montre visuellement comment les objets s'emboîtent — lisible par un
humain qui ne connaît pas les diagrammes objets.

Ce qu'il faut montrer, avec des verbes sur chaque flèche :

- Une **règle** (une consigne de travail) est **rangée dans** un **bundle** (un classeur
  de règles). C'est LA LOI.
- Une **commande** (skill — un outil avec ses sous-commandes) **convoque** des **rôles**
  (agents — des métiers incarnés). C'est L'ÉQUIPE. (Une commande compose aussi d'autres
  commandes — dit dans le glossaire, pas dessiné, pour garder le schéma léger.)
- Un **rôle** **applique** des règles (ses règles d'interaction le suivent partout).
- Une **cérémonie scrum** (grooming, planning, rétro…) est **implémentée par** des
  commandes/sous-commandes — c'est la table de correspondance scrum ↔ ezk.
- Le **profil** est le bon de commande d'une **cible** : il **choisit** des bundles,
  des rôles et des commandes.
- **bind** (le livreur, du moteur) **lit** le profil et **installe chez** la cible —
  le poste (~/.claude), un projet, ou une session.

Trois couleurs porteuses de sens : bleu = LA LOI, or = L'ÉQUIPE, vert = le moteur qui
livre (profil → bind → cible). La cérémonie reste neutre (c'est le monde scrum).
