# Cap — claude-desktop

Matérialise un profil sous forme de **dossiers de skills importables** dans Claude Desktop
(`<name>/SKILL.md` + `scripts/`).

> Tant que ce cap n'est pas écrit, **tu continues d'utiliser tes skills exactement comme
> aujourd'hui** (`claude-skills` + `install.sh`). RIEN n'est cassé par ce nouveau projet.

C'est le cap qui garantit ta contrainte : « pouvoir sauvegarder mes skills et les charger
localement sur mes projets Claude Desktop » pendant toute la transition.
