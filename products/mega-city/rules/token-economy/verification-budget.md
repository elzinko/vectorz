id: token-economy/verification-budget
kind: disposition
level: SHOULD
title: Size verification by the cost of checking
---

- Size verification effort by the COST OF CHECKING, not by the stakes alone
- High stakes + cheap check (a local file, one command) → check it, don't deliberate
- Reserve adversarial / multi-agent verification for the IRREDUCIBLE: runtime
  behaviour, cross-system interaction, judgement — never for a claim one read settles
- A fan-out that re-reads the same local file N times buys confidence already
  available for one tool call
