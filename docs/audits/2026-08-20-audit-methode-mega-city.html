Les 11 contradictions — la vraie maladie

C2 — la seule qui casse quelque chose d'utilisable

Le template de PR installé (.github/PULL_REQUEST_TEMPLATE.md) commence par ## Summary. Or ezk-sprint déclare ## Summary « proscrit », et le propre vérificateur du dépôt (check-pr-body.sh) rejetterait ce template : il exige une ouverture « En clair » visible, alors qu'elle n'y figure que dans un commentaire HTML.

L'asset source, lui, est à jour. C'est la copie installée à la racine qui n'a jamais été régénérée. Fix : une copie de fichier.

C1 · C5naming jamais exécuté
0020 rejette le rename ezk-pr-pilot → ezk-pr ; 0022 le déclare « nom préféré ». Idem ezk-testbed vs ezk-sandbox. Les deux ADR sont « proposé », aucun des noms n'existe. Fusionner 0022 dans 0020 supprime les deux d'un coup.

② Le code — ce qui est cassé

Le finding le plus coûteux : ta gate locale ment

pnpm lint échoue (exit 1) à la racine, à cause d'un unique fichier — .claude/settings.local.json — que Biome n'ignore pas alors que git l'ignore.

La CI est verte parce que ce fichier n'existe pas sur le runner. Mais la gate hôte — seule voie de validation viable puisque Docker est injoignable ici — rend un faux rouge sur toute machine de dev. C'est le pire type de défaut : il entraîne à ignorer la gate.

Casséagir maintenant
Deux scripts dont l'invocation par défaut échoue — check-links.sh et regen-backlog.sh pointent tous deux vers un features/ supprimé en PR #147.

En revanche, du vrai ménage — sans rien réécrire

  1. Supprimer .git/cursor — 18 Mo, soit 47 % du poids. Artefact d'IDE, aucun rapport avec git.
  2. Lancer git gc — 2 719 objets épars pesant 14 Mo contre 4,58 Mio packés. Ramène .git/objects de 19 Mo à ~5 Mo.
  3. Supprimer 22 branches distantes orphelines — PR mergée, branche survivante : le piège --delete-branch depuis un worktree, enfin chiffré.
  4. Ranger le local — 10 branches mergées, 1 worktree périmé (PR #129), 1 stash d'une campagne déjà livrée.

Par quoi commencer

  1. Réparer la gate — ajouter .claude aux ignores de Biome. Une ligne, et pnpm lint cesse de mentir à chaque dev.
  2. Régénérer le template de PR depuis son asset source. Une copie de fichier, et le dépôt cesse de violer sa propre règle.
  3. Bumper @modelcontextprotocol/sdk et gray-matter — couvre 100 % de l'exposition prod réelle.
  4. Trancher la taxonomie — fusionner 0022 dans 0020 en 4 bandes (cérémonies / rôles / artefacts de méthode / outillage). C'est le préalable qui débloque le champ roles:, aujourd'hui posé mais volontairement inerte.
  5. Puis la refonte ADR — archiver 4, fusionner 3, réécrire 6, ratifier 10.
