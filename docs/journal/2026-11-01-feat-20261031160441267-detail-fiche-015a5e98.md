## [20261031160441267] Un git add multi-chemins échoue en entier sur un chemin déjà renommé
- **Coincé** : Après un git mv, citer l'ancien chemin dans git add fait échouer toute la commande (pathspec) ; le commit suivant ne prend que le renommage déjà indexé
- **Réglé** : Ne citer que les chemins qui existent (le git mv a déjà indexé le renommage), contrôler git status puis git show --stat avant de continuer ; corrigé par un amend sur la branche locale
- **Pourquoi** : Deux fois le même jour (sprints 2 et 3) : git add s'arrête à la première erreur et n'indexe rien
