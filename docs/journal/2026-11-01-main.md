# Journal des difficultés — main

## [20261029112813308] Une autre session écrivait dans le même dossier
- **Coincé** : En plein build, git status montrait des fichiers modifiés qui n'étaient pas à moi (une autre session sur le checkout principal) ; elle a ensuite committé et poussé main, avec mes commits locaux
- **Réglé** : Travail déplacé dans un worktree dédié (.claude/worktrees/), checkout principal remis sur main sans mes fichiers ; merge local seulement une fois le checkout propre (ship-merge refuse un dépôt sale)
- **Pourquoi** : Deux sessions sur le même checkout partagent l'index et HEAD : un commit de l'une peut embarquer le travail de l'autre

## [20261029112813308] Gate rouge dans un worktree neuf
- **Coincé** : ezk-cwd-root et project-root-bins échouent (ENOENT features/BACKLOG.md), et deux tests du lanceur échouent quand la branche a du retard sur origin/main
- **Réglé** : Régénérer l'index (bin/regen-backlog.sh <racine du worktree>) avant la gate, et rebaser la branche sur main
- **Pourquoi** : BACKLOG.md n'est plus versionné (ADR-0075) mais ces tests le lisent ; le lanceur avertit sur stderr quand son code retarde sur origin/main
